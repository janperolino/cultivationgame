# Screen inspo

GPT-made screens Jan collected on 2026-10-18, sorted by the system they show. They are layout and mood, not spec: the doors, numbers and mechanics in them are GPT's placeholders, and the design stays as `docs/design.md` has it. A phase's talk opens the folder for its system.

Jan's calls from the talk:

- Each kind of place gets its own layout. A market sprawls, a sect climbs, a wild place is mostly painting; the shared kit (rows, tabs, buttons, gilt) keeps them one game.
- Within a job the controls stay the same (every shop has item rows, a price, Buy), however differently each one is dressed.
- The five Jan loved most, the A6 brief: Jadewater Market, Cloudstep Sect, Misted Herb Valley, Sandglass Oasis and the Quiet Moon Teahouse.
